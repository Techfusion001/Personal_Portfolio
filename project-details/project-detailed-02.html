Unity 3D / C# / FPS Systems

Unity Tactical FPS & Sniper Game Project

Project Overview:

This is a tactical FPS/sniper game project inspired by mission-based shooter gameplay. It focuses on realistic controls, weapon handling, enemy AI, mission systems, terrain design and immersive visual presentation.

Gameplay Systems:

The project includes FPS movement, aiming down sights, recoil handling, burst/fire modes, projectile logic, scopes, binocular/night/thermal overlays, health/damage logic, weapon switching and UI feedback for ammo, objectives and interaction states.

AI & Mission Logic:

Enemy behaviour uses state-based AI such as Idle, Patrol, Alert, Investigate, Search and Combat. Navigation is built around Unity NavMesh, with mission/objective logic for progression, target elimination, extraction and scenario control.

World & Vehicle Work:

The level plan includes a large terrain environment with infiltration areas, refinery/industrial sections, storage warehouse, main compound and extraction zone. Vehicle work includes wheel-collider setup, driver seat logic, braking, acceleration, handbrake and stability handling.

A practical game project focused on full gameplay systems rather than only visuals.
