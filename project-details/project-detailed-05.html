ML-Based Anomaly Detection with Concept Drift

Research Overview:

This MSc research project investigates machine-learning-based anomaly detection where real-world data changes over time. The core challenge is concept drift: model performance can degrade when normal behaviour shifts, even if the system was previously accurate.

Problem Statement:

Traditional anomaly detection models often assume that training and future data follow the same distribution. In real systems such as networks, transactions, sensors or user activity, behaviour changes continuously. This project explores methods that can detect anomalies while adapting to drift.

Planned Methodology:

The work includes literature review, GDPR-aware dataset selection, preprocessing, baseline anomaly detection, drift detection, model comparison and evaluation using suitable metrics such as precision, recall, F1-score, false positive rate and detection delay.

Potential Dataset Direction:

The project is planned around publicly available non-personal or anonymised datasets to avoid GDPR issues. Suitable directions include network intrusion datasets, synthetic streaming datasets or open benchmark datasets designed for anomaly detection and drift evaluation.

Expected Outcome:

The goal is to build and evaluate an adaptive anomaly detection workflow that performs better under changing data patterns than a static baseline model. The project connects data science, cyber-relevant monitoring, model evaluation and real-world AI reliability.

Reliable AI should not only detect unusual behaviour; it should stay useful when the world changes.
