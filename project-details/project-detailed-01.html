Car Selling Marketplace Web System

Project Overview:

This project is a complete car selling marketplace converted from a rental-style template into an Autotrader-style platform. The system supports user accounts, seller packages, paid ad publishing, featured ad options, admin moderation and a database-driven browsing experience.

Main Features:

The platform includes registration/login, active subscription checking, ad posting, image upload validation, brand/category data, search filtering, featured listings, normal listings, admin approval and user dashboard workflows. The business model supports paid ad durations and seller commission logic.

Stripe Checkout was integrated for package payments, with webhook handling to confirm payment status and activate ad publishing rights. The system was designed around package rules such as remaining ad credits, pending payment blocking and redirect logic for users who already have an active subscription.

Technical Stack:

Frontend: HTML, CSS, Bootstrap, JavaScript.
Backend: PHP 8 with PDO.
Database: MySQL.
Payments: Stripe Checkout Session and webhook flow.
Security: server-side validation, prepared statements, CSRF-aware forms and controlled upload rules.

What I Built:

I worked on subscription logic, ad publishing, payment flow, admin/user panel improvements, marketplace browsing, blog system, featured ad sections, package pricing and UI restructuring. The project demonstrates practical full-stack development, payment integration and real marketplace architecture.

A production-style marketplace project built around real seller journeys, payments and admin control.
